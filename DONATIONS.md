# Supporting COLDIRON OS

COLDIRON OS is free software (GPL-3.0-or-later) and it will stay free.
It is developed with AI-assisted tooling and published as a public good
for the Bitcoin self-custody community.

If the project has saved you time or given you peace of mind, a donation
helps keep the development running: new features, security hardening,
hardware testing and — eventually — independent audits.

**Donations are optional and never required.** Nothing here is paywalled,
no feature sits behind a donation wall, and no one will ever DM you asking
for funds.
